# muditdholakia.github.io

Personal website and CV of Mudit Dholakia: https://muditdholakia.github.io

A static site (HTML, CSS and JavaScript modules) with no build step. It uses three.js (MIT),
GSAP with ScrollTrigger, SplitText and ScrambleText (GSAP's no-charge standard licence) and
Lenis (MIT), served from `vendor/`.

Company, school and product logos belong to their owners and appear only to identify
employers, schools and the tools used.
